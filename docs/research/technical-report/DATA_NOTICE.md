# Data attribution and evidence scope

Source dataset: BIRD-SQL Mini-Dev, by the BIRD Team.
https://huggingface.co/datasets/birdsql/bird_mini_dev

The official dataset card lists Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0):
https://creativecommons.org/licenses/by-sa/4.0/

The underlying study uses an adapted five-table projection with source rows preserved. The paper is a custom, small evaluation, not an official BIRD benchmark score. No endorsement or collaboration is implied.

The bundled aggregate observations and plotted ranking are derived from the completed validation report. They support reproduction of the figures and reported descriptive totals. Any redistribution of adapted source data must preserve applicable attribution and share-alike obligations. A repository's software license does not replace the dataset license. No raw database is included in this package.
