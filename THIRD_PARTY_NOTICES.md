## Synthetic examples

The delivery fixtures are generated by
[data-investigation-agent/fixtures/build_dev.py](data-investigation-agent/fixtures/build_dev.py).
The `rate_meaning` and `public_metadata` test fixture directories contain small
original synthetic regression inputs. The
[simulation bundle](data-investigation-agent/examples/simulation_bundle/catalog.json)
and its [recorded responses](data-investigation-agent/examples/simulation_responses.json)
are hand-authored examples, not outputs from a paid model or experimental results.

These inputs contain no employer, patient or production records. Catalogs and
fixture descriptions state their intended use. A synthetic declaration must not
be applied to real data contributed later; document its origin and rights.

Neither that dataset nor its reference answers are redistributed here; the
toolkit's Apache-2.0 license does not replace the dataset's license.

## Build and repository tooling

Builds use separately installed `build`, `setuptools` and `wheel` packages.
The [hosted workflow](.github/workflows/ci.yml) references GitHub's checkout and
setup-python actions by fixed revisions. These tools are not copied into the
project distribution and remain subject to their own upstream terms. Runtime
and offline tests need only the standard library.

The README displays a GitHub Actions badge and static Shields.io badges. They
summarize the linked workflow, license, tested Python versions and alpha status;
they are not vendored dependencies or evidence of sponsorship, usage or endorsement.
